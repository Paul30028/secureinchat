Check the production relay

Your browser opens a secure WebSocket to the relay, measures the handshake and checks the challenge. No message content is involved in this diagnostic.

Live relay diagnostic goes here

Keep the existing working control and result panel. Restyle its outer container using the classes in subpages.css; do not recreate the test with dummy values.

Relay endpoint: wss://ws.secureinchat.com

What the test measures

1
Network connection

Whether a secure WebSocket connection can be opened from this browser.

2
Handshake time

Browser-to-relay open time in milliseconds; it is not an end-to-end message latency measurement.

3
Relay challenge

Whether the relay sends the expected authentication challenge.

Read the limits

A successful relay test is not an independent security audit, and it does not prove that a future client is secure.

Cryptographic building blocks

These are design descriptions, not an independent audit or a legal certification.

Curve25519

Elliptic-curve key agreement for client devices.

AES-256-GCM

Authenticated encryption intended to protect confidentiality and integrity of message payloads.

HKDF

Context-separated derivation of session and message keys.
