METHOD AND LIMITS

What this page can and cannot tell you.

Text mode: pattern matching only

It recognises a small set of common formats. It is not a semantic review and does not understand the context of a sentence.

  • Email addresses.
  • Phone-like numbers, including Chinese mainland mobile formats.
  • Chinese resident ID numbers with a valid birth date and check character, and US SSN-like formats.
  • Common access-key, token, JWT and private-key formats.
  • Payment card numbers that pass the Luhn check.
  • IPv4 addresses.

Names, street addresses, account numbers in other formats, context and secrets in other formats are not detected.

Link mode: structure, not a safety verdict

It reads the scheme, host, path and query without contacting the host. It marks common tracking parameters and key names that often carry session or identity data.

  • It does not open the link, follow redirects, or make a request to the destination.
  • It does not know what a query value contains or whether a site is trustworthy.
  • A link with no tracking parameters can still be malicious. A short or clean-looking address is not a safety signal.
  • Quick copy is withheld when the query has session or identity-like key names.

Where the data goes

The workspace runs in this tab. The page code makes no network request after it loads and uses no localStorage, sessionStorage or cookies. Your text or link is cleared when you switch modes, press Clear session, or leave the page. Copy and replacement happen only when you press the button. The page loads its own CSS, JavaScript and, when present, self-hosted font files from this site.
