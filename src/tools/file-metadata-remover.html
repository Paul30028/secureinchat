What it removes

Most files carry a block of hidden data next to the content you see. A phone photo can hold the exact coordinates where you stood, the time and the device model. A Word or PDF file can hold the author, the company, the software that wrote it, and the times it was created and last edited. A video or an audio file can hold the device, the software and the date. Whoever receives the original file can read all of it with free software.

This page lists what the file holds, then makes a copy without it. The original file is not changed. The listing, the cleaning and the second scan all happen in your browser, so the file never leaves your device.

The orientation tag of a photo is kept on purpose, so a photo does not come out turned. For HEIC photos and MP4 video the library clears the metadata bytes where they sit instead of rebuilding the file, so the cleaned copy has the same size as the original. That is normal: the data is gone, the empty space stays.

What it does not do

It does not change what the file shows. The text of a document and the faces, signs and landmarks in a photo are still there. Hidden data is only one way a file gives something away, so read the content as well before you share it.

Old Office formats (.doc, .xls, .ppt) are not supported. Open the file and save it as .docx, .xlsx or .pptx, then clean the new file. Formats that are not in the list are refused before they are read.

It handles one file at a time, up to 200 MB, and does not unpack archives. A file is only cleaned if it can be read: a damaged file is reported, not repaired.

After cleaning, the page scans the new file again and shows what is left. Some values belong to the file structure and cannot be removed without breaking the file; those are listed instead of hidden. A short list is a check, not a promise that the file is safe.

How it works

Everything runs in this tab. The file is read into memory, the file type is detected, the metadata is listed and removed by a WebAssembly module, and the result is scanned one more time before it is offered as a download. No file is uploaded, nothing is stored, and the page loads no analytics.

The cleaning engine is the open source metadata-remover project by iAnonymous3000, used under the MIT licence. The licence text that ships with the build is at /tools/assets/mr/LICENSE.txt.

Frequently asked questions

Is my file uploaded?

No. The file is read, cleaned and scanned again inside this page with WebAssembly. There is no upload and the page stores nothing.

Which formats work?

JPEG, PNG, WebP, AVIF, GIF, HEIC, HEIF, TIFF, SVG, MP4, MOV, MP3, FLAC, WAV, OGG, PDF, DOCX, XLSX, PPTX, ODT, ODS, ODP and EPUB. Old Office files (.doc, .xls, .ppt) are not supported: save them as .docx, .xlsx or .pptx first. Anything else is refused before it is read.

Why is my HEIC or video the same size after cleaning?

For HEIC and MP4 the library clears the metadata bytes where they are instead of rebuilding the file, so the size stays the same. The data is gone; the empty space remains. This is normal.

Will the content change?

No. Only hidden metadata is removed. The text of a document, and the faces and street signs in a photo, are still there. The orientation tag is kept, so a photo does not turn.

Why does the second scan still show something?

A few values are part of the file structure and cannot be removed without breaking the file. The page lists them after cleaning instead of hiding them. If that list matters to you, do not share the file.

Which library does this use?

The open source metadata-remover by iAnonymous3000, used under the MIT licence. The licence text is at /tools/assets/mr/LICENSE.txt and the source is at github.com/iAnonymous3000/metadata-remover.
