01The local toolkit

Start with the local tools

These tools run in your browser and send nothing. They only clean what the browser can read — and each page shows you what it does and does not do.

Local

Photo Metadata Remover

Before you send a photo, remove GPS, camera model and timestamps.

File Metadata Remover

Before you send a Word file or PDF, clear author, revision history and hidden properties.

Open tool → Local

Text Redactor

Before you paste text into an AI chat or send an email, replace emails, phone numbers and ID numbers. It replaces the text itself, not a box drawn over it.

Open tool → Local

Link Checker

Before you open a strange link, see its tracking parameters and host — without opening or sending it.

Browser Fingerprint Test

Check the cleaning yourself.

Every cleaning tool page lists the network requests it makes. While a file is being cleaned, you can watch that list and see whether anything leaves the browser.

It shows which addresses the page contacted and when. Use it as evidence, then decide for yourself.

These tools have limits.

Local tools only clean what the browser can read. Limited-network tools send the first 5 characters of a SHA-1 hash. Network tools send your IP or URL to third-party lookup services.

Encrypted messaging is still being built.

The chat client is developed separately from the privacy tools. A relay forwards only ciphertext it cannot decrypt — and the threat model says plainly what it can and cannot hide.
