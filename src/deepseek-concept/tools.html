01Understand the data flow

Read the label before you trust the result.

“Local processing” means the relevant work happens in your browser. Some tests still need an external request to observe a public-facing value.

Local processing

The work happens in your browser. Nothing is sent while you use it for the relevant task.

Network lookup

The tool contacts an external lookup service to observe a public value (e.g. your IP or a URL).

Limited lookup

Only a short hash prefix is sent — e.g. the first 5 characters of a SHA-1 hash — never the raw password.

1 · Read the label

Three behaviours, three labels

Local processing, network lookup and site request describe different behaviours. The label on each tool tells you which one applies.

2 · Check the limitation

A clean result is not proof

A clean result is not proof of anonymity, and a URL structure check cannot prove that a destination is safe.

Every cleaning tool page lists the exact network requests it makes. While a file is being cleaned, you can watch that list and see whether anything leaves the browser — use it as evidence, then decide for yourself.
