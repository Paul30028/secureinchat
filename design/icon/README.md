# App icon sources (2026-11-04)

Original vector drawings, 108×108 canvas (Android adaptive icon), main shapes inside the central 66×66 safe zone.

- `a-daybreak.svg`: proposed main icon ("Daybreak": a sun rising inside a chat bubble = the Today screen).
- `a-daybreak-mono.svg`: its monochrome layer for Android 13 themed icons (black = drawn; the sun is cut out with a gap).
- `d-wheat.svg`: proposed alternate "community edition" icon (wheat), selectable in the app.

Colours: deep teal #123B3A, paper #F4EFE4, morning gold #E3A23B.
Status: proposal, waiting for Paul's choice. See the report "SecureInChat 深化设计与 GitHub 动向分析".
`../ui-direction-2026-11-04.png` is a mock of the proposed onboarding and Today screens (example content).
