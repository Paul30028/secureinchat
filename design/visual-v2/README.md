Rules used in the sample (to become the spec once Paul approves the look):
- Canvas 760×400, 8 px grid, 24 px outer margin. Zones rx 12, cards rx 8–12, small parts rx 4–6.
- Colours: only the live brand set — #FAF8F3 background, #D7E6E1 your-device zone, #123B3A structure and the relay, #2D6B60 encrypted path, #8DB5AA quiet details, #E3A23B a request that leaves your device (and the seal). White cards.
- Strokes: 1.5 for structure, 3 for the encrypted path. Dashed amber = leaves your device; dashed dark border = someone else's server.
- One soft shadow (dy 2, blur 3, 12 % of #123B3A) on cards only.
- No words inside the SVG. Numbered badges 1–n are explained in the HTML caption, which can be translated.
