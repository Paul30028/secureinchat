方法与局限

检查什么

utm_source、fbclid、gclid 这类追踪参数；@ 前面用来遮住真实网站的文字；直接用 IP 地址的链接；冒充熟悉名字的其他文字字符（会显示解码后的样子）；未加密的 http；不常见的端口；藏住目标网址的短链接；出现在别人网站上的知名品牌名；一长串子域名；以及藏在链接里的第二个网址。

不做什么

它不打开链接，不拿链接去钓鱼数据库里查，也不检查网页内容。一个名字看起来很普通的新骗局网站不会显示任何危险迹象。品牌检查只覆盖一份常被冒充的公司短名单，而且只匹配完整的词。最稳妥的习惯不变：凡是涉及登录或付款的，都从你自己的书签或应用打开那项服务，而不是点链接。

你的链接如何处理

链接只在这个页面里处理。不会发给我们或任何人，页面也不加载统计脚本。相关工具：分享前给文字脱敏、账号安全自查。

常见问题

链接会被打开或发送到别处吗？

不会。检查在这个页面里进行。链接不会被打开、抓取，也不会发给我们或任何信誉查询服务，什么都不保存。

“没有发现危险迹象”就说明链接安全吗？

不是。这些是针对常见套路的本地检查。一个用普通名字新建的钓鱼网站也能通过。请核对网站名是否正是你预期的那个；拿不准时，不要点链接，而是从你自己的书签或应用打开那项服务。

去掉追踪参数会让链接失效吗？

通常不会。工具只去掉已知用于追踪的参数，比如 utm_source 或 fbclid。如果网页打不开了，就用原来的链接。

为什么不拿链接去钓鱼网站数据库里查？

数据库查询会把你的链接发给第三方，而链接里可能带有个人令牌。以后我们可能把它做成一个需要你手动打开的选项，并在页面上写明是哪家服务。
