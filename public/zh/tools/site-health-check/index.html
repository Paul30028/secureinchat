它检查什么

本工具从 Cloudflare 的服务器加载一个公开网站的首页，报告访客或搜索引擎最先遇到的情况：页面是否通过 HTTPS 加载、普通 HTTP 是否被跳转、状态码和跳转、服务器多快开始响应、常见的安全响应头、标题、描述、规范链接、视口、语言和主标题、是否禁止收录，以及 robots.txt 和站点地图是否存在、能否读取。

它不检查什么

它只看首页，不看每一个页面。它不读取证书，所以无法提醒你证书快要到期。响应时间来自一个地点，其他地方的访客看到的可能更快或更慢。所有检查都通过，也不代表网站安全或排名好。这是一次初步检查，指出常见、可以修好的缺口。

检查结果由本站接口以英文返回，本页在你的浏览器里把它们译成中文；响应头名称、响应头的值和网页标题等原始数据保持原样。

你输入的地址如何处理

地址会发送到本站，本站抓取该网站的公开页面并返回结果。我们的代码不保存也不记录地址和结果。为本站提供服务的 Cloudflare 会像看到任何网页请求一样看到这次请求。只能检查标准网页端口上的公开网站，抓取请求会标明自己是 SecureInChatSiteCheck。请只用于你拥有或管理的网站。完全在浏览器里运行的检查，见其他工具。

常见问题

我输入的地址会被保存吗？

我们的代码不保存也不记录它。请求会经过为本站提供服务的 Cloudflare，所以 Cloudflare 会像看到任何网页请求一样看到它。

为什么不能检查 IP 地址或内部网站？

本工具从公网服务器抓取页面，所以只接受 80 和 443 端口上的公开域名。IP 地址、本地名称和内部主机都会被拒绝。

为什么结果全部正常也不代表网站安全？

这些只是对首页的表面检查。它们能发现缺少 HTTPS 跳转、常见安全响应头这类基础问题，但不会测试你的代码、登录或服务器。

为什么响应时间和其他工具不一样？

它是在 Cloudflare 的一个节点上，测到服务器开始响应为止。其他工具从别的地方测量，包含的步骤也可能不同。

可以把结果发给客户吗？

可以。用「复制文字报告」，它会列出每项检查的状态和需要修改的地方。发送前请先读一遍，因为它只描述首页。
