这个测试会读取什么

任何你访问的页面都能不问就读取下面这些信号。这个测试把它们读出来，并告诉你哪些会帮助追踪器认出你，以及你的浏览器已经启用了哪些防护。

  • 画布：把同一张图画两遍。稳定的结果本身就是一种信号。每次都不同说明你的浏览器或扩展在有意加噪。
  • 显卡：WebGL 能报告的 GPU 名称。有些浏览器会把它藏起来。
  • 全局隐私控制和不跟踪：你的浏览器是否发送退出信号。
  • 浏览器和设备：浏览器标识、语言、时区、屏幕和硬件信息。

这个测试无法告诉你什么

它不测试字体、音频处理或每一个 API，也无法说明你的特征组合有多罕见。请把结果当作一份「浏览器暴露了什么」的清单，并在更换浏览器、设置或扩展之后再运行一次。如果你更关心一条链接是否可疑，可以试试链接检查器。

常见问题

什么是浏览器指纹？

网站会从你的浏览器读很多小细节，比如屏幕大小、字体、图形输出和语言，再把这些组合成一个值，不用 Cookie 就能认出你。

这个测试能告诉我自己有多独特吗？

不能。真正判断独特性需要大量其他浏览器的样本，本页没有这样的数据。它展示的是你的浏览器暴露了什么，以及哪些防护已经生效。

画布结果每次不同是什么意思？

本页把同一张图画两遍。如果结果不一样，说明你的浏览器或扩展在有意加噪，这会让画布无法再作为稳定的标识。Brave 和某些 Firefox 设置会这么做。测试能看出差异，但无法确认具体手段。

画布哈希稳定是不好的吗？

在大多数浏览器里这是正常的。它之所以值得注意，是因为追踪器会把它和其他信号合起来用。在同一台设备上换几个浏览器比对哈希值，就能看出有多少是你这台设备特有的。

什么是全局隐私控制？

一种浏览器信号，请求网站不要出售或分享你的数据。有些司法辖区要求网站把它当成退出请求。它不会向网站隐藏任何东西。

不跟踪有用吗？

很少有用。大多数网站会忽略它；而且因为打开的人很少，打开它反而可能成为一个额外的、让你更容易被区分出来的细节。

怎样减少被指纹识别？

使用会随机化或阻止高价值信号的浏览器，保持更新，避免不常用的扩展和设置，也不要把窗口调整到少见的尺寸。任何改动之后，重新运行一次这个测试。

本页会保存我的数据吗？

不会。所有计算都在你的浏览器里完成，不发送任何内容。页面不设置 Cookie，也不加载统计脚本。
