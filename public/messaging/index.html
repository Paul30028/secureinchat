Architecture

The server forwards. It never understands.

01 / 03

Sender encrypts locally

Message content and session keys are processed on the device before anything is sent.

Plaintext never leaves the device
02 / 03

Blind relay forwards

The relay routes encrypted payloads without the keys needed to decrypt them.

Cannot read message content
03 / 03

Recipient decrypts locally

Only the intended recipient device decrypts and checks the message.

Decrypted at the edge

Cryptography

Established primitives, minimal trust surface.

Key agreement

Curve25519

Elliptic-curve key agreement for modern client devices.

Authenticated encryption

AES-256-GCM

Protects both confidentiality and integrity of each message.

Key derivation

HKDF

Context-separated key derivation for session and message keys.

Data minimisation

No message storage

The relay is designed without persistent storage of message content.

These describe the design. They are not a legal certification or an independent audit. What the relay can and cannot see is explained in what a blind relay can and cannot know.
