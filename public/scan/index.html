What a website can read
before you allow anything.

Any normal website can already read a set of details from your browser. This scan reads the same details locally and shows you each one, who can see it, and how to reduce it.

This part does not use the network. It sends nothing and writes nothing to storage. Nothing starts until you press the button.

      04 / LIMITS

      What this cannot tell you

      No uniqueness score

      This page has no dataset of other browsers, so it cannot say you are unique or give a percentage. A value that looks unusual here is not proof that a site can single you out; a common value is not proof that it cannot.

      No device model judgement

      The platform and user-agent lines are shown as the browser reports them. This page does not infer a device model, and browsers may hide, round or rewrite these values.

      Who can read it

      Every local item is readable by scripts on any website you visit, not only by this page. Some values, such as the user agent and language, are also sent in normal HTTP request headers.

      Memory only

      Results and the saved comparison live in JavaScript memory. This page uses no cookie, localStorage, sessionStorage or IndexedDB. Reloading or closing the tab clears them, and the browser may clear them earlier if it reclaims the tab.
