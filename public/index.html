Zero-Knowledge Architecture

The server forwards. It never understands.

Every sensitive operation stays at the edge. The relay receives only encrypted payloads required for delivery.

01 / 03

Sender Local Encryption

Message content and session keys are processed locally before any network transmission.

PLAINTEXT NEVER LEAVES DEVICE
02 / 03

Blind Relay Server

The relay routes opaque cipher payloads without possessing the keys required to decrypt them.

CANNOT READ MESSAGE CONTENT
03 / 03

Recipient Local Decryption

Only the intended recipient device reconstructs and decrypts the authenticated message.

DECRYPTED AT THE EDGE
Security Matrix

Modern cryptography. Minimal trust surface.

SecureInChat combines established primitives with client-side key custody and a relay architecture designed to minimize data exposure.

Curve25519

Efficient elliptic-curve key agreement for modern client devices.

AEAD

AES-256-GCM

Context-separated key derivation for session and message-key workflows.
