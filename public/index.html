See what you give away. Then switch it off.

Before you send a photo, paste text into an AI chat, or open a strange link, check what you expose. Everything runs in your browser.

Open the workspace Browse all tools

Start with the local tools

These tools run in your browser and send nothing. Account checkup is a checklist that stays on your device too.

Photo Metadata Remover

Before you send a photo, remove GPS, camera model and timestamps.

File Metadata Remover

Before you send a Word file or PDF, clear author, revision history and hidden properties.

Text Redactor

Before you paste text into an AI chat or send an email, replace emails, phone numbers and ID numbers. It replaces the text itself, not a box drawn over it.

Link Checker

Before you open a strange link, see its tracking parameters and host.

Browser Fingerprint Test

After you switch browsers or change settings, check which traits are still visible.

Account Checkup

A checklist you tick off item by item: sign-in, recovery, two-factor.

Not sure where to start? Take the privacy checkup

Check the cleaning yourself.

Every cleaning tool page lists the network requests it makes. While a file is being cleaned, you can watch that list and see whether anything leaves the browser.

It shows which addresses the page contacted and when. Use it as evidence, then decide for yourself.

Read the data-flow notes

These tools have limits. Local tools only clean what the browser can read. Limited network tools send the first 5 characters of a SHA-1 hash. Network tools send your IP or URL to third-party lookup services. Read the label definitions and data flows

Encrypted messaging is still being built.

The chat client is developed separately from the privacy tools. No release date has been announced.
