プライベートワークスペース / ローカル文字チェック

共有する前に、何を送ろうとしているか確かめよう。

テキスト、リンク、対応している画像をブラウザ内で確認できます。何が見つかり、何を見逃す可能性があり、どこから先を自分で決めるのかを確かめてください。

テキストのリアルタイムチェック このタブ内で実行 / アップロードなし

メッセージ、メール、ログを貼り付けてください。このタブ内だけで読み取り、ページには保存しません。

入力を始めると、ルールで見つかる項目が表示されます。

    パターン一致のみです。氏名、住所、文脈、特殊な形式は見逃すことがあります。「見つからない」は安全の保証ではありません。

    ワークスペースを開く

    アカウント不要。自動送信はありません。

    01 / 送る前に

    共有する前の三つの場面。

    それぞれ対応するモードでワークスペースを開きます。ワークスペースが正式なツールで、このページは手早く見るための入口です。

    01 / テキスト

    これから貼り付けるメッセージ

    テキストを貼り付けると、ルールが検出できるメール、電話番号らしい数字、公的 ID の形式、カード番号、アクセスキーを表示します。

    テキストを確認 →
    02 / リンク

    これから開くリンク

    リンクを開かずにアドレスだけを読みます。追跡パラメータや、セッション・身元情報を含みやすいキー名を確認できます。

    リンクを確認 →
    03 / 画像

    これから送る写真

    対応形式と制限を確認し、このタブ内で新しいコピーを作ります。ダウンロードは、あなたがボタンを押したときだけ始まります。

    画像を確認 →

    02 / プロダクト

    二つのプロダクト、二つの役割。

    ローカルツールとメッセンジャーは別のプロジェクトです。状態は推測ではなく、ここに明記します。

    03 / 原則

    プライバシーは、自分で確認できる境界です。

    このサイトのすべてのツールは三つのルールに従います。詳しい説明とデータの流れは原則ページにあります。

    1. 01

      まずローカルで処理する

      確認はブラウザ内で動きます。テキストを入力している間、リアルタイムチェックはリクエストを送りません。

    2. 02

      限界を明記する

      ルールは形式に一致するだけで、氏名、住所、文脈、特殊な書き方は理解しません。そのことを結果のそばに書きます。

    3. 03

      次に何をするかはあなたが決める

      コピー、置換、ダウンロード、送信は、対応するボタンを押すまで起きません。
