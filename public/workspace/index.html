What re-encoding does and does not do
  • It writes a new file and drops most metadata chunks, including common EXIF and text chunks. It does not verify that every metadata block is gone.
  • It can change quality, colour and transparency. JPEG and WebP are encoded at quality 0.92; PNG is lossless but its bytes and colour profile can still change.
  • Animated PNG or WebP files become a single still frame.
  • It does not inspect what is visible in the picture: faces, house numbers, screens or other private details remain in the image.

METHOD AND LIMITS

What this page can and cannot tell you.

Text mode: pattern matching only

It recognises a small set of common formats. It is not a semantic review and does not understand the context of a sentence.

  • Email addresses.
  • Phone-like numbers, including Chinese mainland mobile formats.
  • Chinese resident ID numbers with a valid birth date and check character, and US SSN-like formats.
  • Common access-key, token, JWT and private-key formats.
  • Payment card numbers that pass the Luhn check.
  • IPv4 addresses.

Names, street addresses, account numbers in other formats, context and secrets in other formats are not detected.

You can optionally download a small local AI model that suggests English names, addresses, organisations and a few other items. It is off by default, the download comes from this site only, and every suggestion is unchecked until you confirm it. Our test with 80 English samples found about 80% of the personal information, and about 85% of what it found was correct; it misses some and flags some wrongly. Chinese and other languages still use the rules only.

Link mode: structure, not a safety verdict

It reads the scheme, host, path and query without contacting the host. It marks common tracking parameters and key names that often carry session or identity data.

  • It does not open the link, follow redirects, or make a request to the destination.
  • It does not know what a query value contains or whether a site is trustworthy.
  • A link with no tracking parameters can still be malicious. A short or clean-looking address is not a safety signal.
  • Quick copy is withheld when the query has session or identity-like key names.

Image mode: re-encoding, not a privacy check

It reads one JPEG, PNG or WebP file up to 25 MB and 40,000,000 pixels, checks the reported MIME type and the first bytes, then decodes and re-encodes the picture in this tab.

  • Re-encoding drops most metadata chunks, including common EXIF and text chunks, but it does not prove that every metadata block is gone.
  • Quality, colour and transparency can change. JPEG and WebP are encoded at quality 0.92; PNG is lossless and has no quality setting.
  • Animated PNG or WebP files become a single still frame.
  • It does not detect faces, house numbers, screens, documents or anything else visible in the picture.
  • The copy is downloaded only after you press its button. The page does not open, upload or send the image.

Where the data goes

Until you turn on the optional local AI, the workspace makes no network request after it loads, and it uses no localStorage, sessionStorage or cookies. The local AI stays off until you press its download button; when you do, the model files (about the size shown in that block) come from this site only, are cached in this browser and can run offline. Your text is processed in a worker on this page and is never uploaded. Your text, link or image state is cleared when you switch modes, press Clear session, or leave the page; switching modes or clearing keeps the cached model, while Delete model removes it. Copy, replacement and download happen only when you press the relevant button. The in-memory download URL is revoked on the same clear, mode switch or exit; a file you have already downloaded is outside this page. The page loads its own CSS, JavaScript and, when present, self-hosted font files from this site.
