How a password breach check works without sending your password

How k-anonymity lets a breach check compare your password against billions of leaked ones by sending only a five-character hash prefix, what it reveals, and what it cannot tell you.

By Paul2026-10-20

Checking a password against a list of leaked passwords sounds like it requires handing the password to someone. It does not have to. The method used by the Pwned Passwords service, and by our password checker, sends only a small piece of a hash and compares the rest on your device.

The steps

  1. Your browser computes the SHA-1 hash of the password. That is 40 hexadecimal characters.
  2. It sends only the first five characters to the service.
  3. The service replies with every hash suffix it holds that begins with those five characters, each with a count. A reply holds several hundred entries.
  4. Your browser looks for the remaining 35 characters in that reply. If they are there, the password is in the breach data, and the count says how often.

Why this is called k-anonymity

Any five-character prefix is shared by many different passwords, so the service cannot tell which one you checked. The password and the full hash never leave your browser.

What it still reveals

It is a reduction in what is disclosed, not zero. The service sees your IP address and the prefix. A network observer can see that you ran a check. Sending a request for each key press would reveal much more, so the checker only runs when you press the button. It also asks for padded replies, which adds fake entries so the size of the reply does not hint at the answer.

What a result means

  • Found: this exact password has appeared in a published breach, so attackers try it early. Stop using it everywhere.
  • Not found: it is not in that list. It may still be weak, or it may have leaked in a way that was never published.

That is why the checker shows strength and breach status as two separate results. A long random password used on one site is the goal, and a breach check is a way to catch the cases where that did not happen.
