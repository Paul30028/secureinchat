What it does

Paste text and the tool replaces emails, phone numbers, IP and MAC addresses, card numbers, IBANs (checked with the standard checksum), Chinese mainland mobile numbers, Chinese resident ID numbers (checked with the GB 11643 check digit and birth date), API keys, tokens, passwords inside URLs and private keys with labelled placeholders such as [EMAIL_1]. The same value always gets the same placeholder, so a log stays readable after redaction. This is useful before you paste a log, a config or an email into a bug report, a forum or an AI assistant.

What it does not do

It finds patterns, not meaning. Names, street addresses, company names and anything written in an unusual format are not detected. Add names you know about under "Names and other words to hide" and they are replaced with [NAME_1], [NAME_2] and so on; the tool does not discover names by itself. Always read the result before you share it. A card number is only replaced if it passes the standard checksum, so a made-up number may be left alone.

How your text is handled

The text is processed in this page. It is not uploaded, logged or stored, and the page loads no analytics. Your browser or an extension may still keep what you type, so use a private window for sensitive material. Related: remove metadata from a photo.

Frequently asked questions

Is my text sent to a server?

No. The matching runs in your browser. The page makes no network request when you paste or redact text.

Why did it miss a name or an address?

It matches patterns such as emails and numbers. A name has no fixed pattern, so it is not detected. If you know which names or words to hide, add them under "Names and other words to hide"; the tool does not find them for you. Check the output yourself before you share it.

Why is the same placeholder used twice?

Equal values get the same placeholder, for example [IP_1] or [EMAIL_1], so you can still follow what happened in a log after redaction.

Can it find every API key?

No. It recognises common formats such as AWS, GitHub, Slack, Google and OpenAI-style keys, plus JSON Web Tokens and private key blocks. Other secrets, and keys in a custom format, can pass through. Rotate any secret that has been exposed.

Can it redact a file?

Not yet. Paste the text into the box. For photos, use the photo metadata remover.
