Password generator

Two different questions

A password can fail in two ways. It can be easy to guess, or it can already be known because a site that held it was breached. This page answers both separately, because a long, complicated password that was leaked is still unsafe, and a short one that was never leaked is still easy to guess.

  • Strength is estimated in your browser from length, variety and simple patterns. Nothing is sent.
  • Known breaches is checked only when you press the button. Your browser sends the first five characters of the SHA-1 hash of the password to the Pwned Passwords service and compares the reply itself.

What to do with the result

  • If a password is found in breaches, stop using it everywhere.
  • Prefer length. A long random password or a phrase of several unrelated words beats a short one with symbols.
  • Use a different password on every site, ideally from a password manager, and turn on two-factor sign-in for important accounts.

Frequently asked questions

Is my password sent anywhere?

The strength estimate is computed in your browser and nothing is sent. The breach check runs only when you press the button. It sends the first five characters of the password's SHA-1 hash to the Pwned Passwords service, never the password or the full hash, and your browser compares the answer locally.

What does the breach check actually tell me?

Whether this exact password appears in the public breach data that Pwned Passwords holds, and how many times. Found means it is known to attackers. Not found does not mean it is safe, only that it is not in that list.

Is sending the first five characters of the hash safe?

It is a trade-off, not zero disclosure. Many thousands of different passwords share any five-character prefix, so the service cannot tell which one you checked. The request also asks for padded responses so their size does not reveal much. A network observer still learns that you ran a check.

How accurate is the strength estimate?

It is a rough estimate from length, variety and a few common patterns. It does not know every dictionary or leaked list, so a password it likes can still be weak. Use the breach check, make passwords long, and use each one on a single site.

Is the generator random?

Yes. It uses your browser's cryptographic random number generator and picks each character with rejection sampling so no character is favoured. It leaves out look-alike characters such as 0, O, 1 and l. Nothing is sent or stored.

Should I use a password manager?

For most people, yes. It lets you use a long, different password on every site without remembering them. This page does not store anything and is not a replacement for one.

Does this page store my password?

No. The field is not saved by the page, there are no cookies, and the page loads no analytics. Your browser or a password manager may offer to save what you type, so use a private window if you are testing a real password on a shared computer.
