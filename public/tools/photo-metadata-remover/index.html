What is hiding in your photos

Most phone photos are saved with a block of hidden data called EXIF. It can include the exact coordinates where you stood, the time, and the model of your device. If you post or send the original file, whoever receives it can read that data with free software.

This page shows what a JPEG contains, then makes a copy without it. Your original file is never changed. The check and the cleaning both happen in your browser, so the photo does not leave your device.

Before you share a photo

  • Remove metadata from the file, as this page does.
  • Look at the picture for details that give away a place: signs, house numbers, views from a window.
  • Turn off location tagging in your camera app if you rarely need it.

Frequently asked questions

Is my photo uploaded?

No. The file is read and re-encoded inside this page. There is no upload, and the page's code stores nothing. The page loads no analytics.

What metadata do photos contain?

Phone and camera JPEGs usually carry EXIF data: the device make and model, the date and time, often GPS coordinates, and sometimes software, lens or serial number.

Do social networks remove metadata for me?

Some do when you upload, but you cannot tell which, and sending a photo by email, cloud link or some messengers can pass the original file through. Remove it yourself before you share.

How does removal work here?

The page decodes the image and draws it onto a blank canvas, then saves that canvas as a new file. Metadata is not part of the pixels, so it is not copied. The page then reads the new JPEG again to check that no EXIF is left.

Will image quality change?

A JPEG is re-encoded at high quality, so there can be a small loss. PNG output is lossless. The embedded colour profile is dropped, which can shift colours slightly in some viewers.

Which formats work?

JPEG, PNG and WebP, if your browser can decode them. HEIC and animated images are not supported. Only JPEG metadata is shown before cleaning, but cleaning removes metadata from all supported formats.

Does it remove what is in the picture itself?

No. A street sign, a face or a landmark in the photo can still give away where you are. This tool only removes hidden data.
