What it checks

The tool loads the home page of a public website from a Cloudflare server and reports what a visitor or a search engine would meet first: whether the page loads over HTTPS, whether plain HTTP is redirected, the status code and redirects, how quickly the server answers, the common security headers, the title, description, canonical link, viewport, language and main heading, whether indexing is blocked, and whether robots.txt and a sitemap are present and readable.

What it does not check

It looks at the home page only, not every page. It does not read the certificate, so it cannot warn you that a certificate is about to expire. The response time comes from one location, so visitors elsewhere may see more or less. Passing every check does not mean a site is secure or well ranked. It is a first look that points at common, fixable gaps.

How the address you enter is handled

The address is sent to this site, which fetches the public pages of that website and returns the result. Our code does not store or log the address or the result. Cloudflare, which serves this site, sees the request as it does for any page. Only public websites on the standard web ports can be checked, and the requests identify themselves as SecureInChatSiteCheck. Use it on sites you own or manage. For checks that run entirely in your browser, see the other tools.

Frequently asked questions

Is the address I enter stored?

Our code does not store or log it. The request goes through Cloudflare, which serves this site, so Cloudflare sees it as it sees any request to a web page.

Why can I not check an IP address or an internal site?

The tool fetches pages from a public server, so it only accepts public domain names on ports 80 and 443. IP addresses, local names and internal hosts are refused.

Why does a good score not mean my site is secure?

These are surface checks of the home page. They catch missing basics such as HTTPS redirects and common security headers. They do not test your code, your login or your server.

Why is the response time different from other tools?

It is measured from one Cloudflare location until the server starts to answer. Other tools measure from other places and may include different steps.

Can I send the result to a client?

Yes. Use Copy report as text, which lists each check with its status and what to change. Read it first, because it only describes the home page.
