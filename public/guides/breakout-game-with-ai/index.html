What you build

A complete Breakout game in a single HTML file: paddle, 40 bricks, three lives, scoring, keyboard, mouse and touch control. You paste prompts into an AI and check the result; you do not write the code by hand.

Free preview: Prompt 1

Write a single-file HTML5 canvas Breakout game (no libraries, no external assets). 480x560 canvas; 8 columns x 5 rows of bricks; ... Expose window.__game = { get(), reset(), start() } ... Return only the file.

What was verified, and what was not

  • Verified: on 2026-10-20 a separate AI session that had not seen the original ran the prompts from scratch. Prompt 1 produced a working game on the first try.
  • Verified: in 13 of 13 runs the game passed the checks for starting, launching, paddle limits, losing a life, game over, restart and console errors.
  • Not stable: the check that an autoplayer wins within 120 seconds passed in 9 of 14 runs. The game was always winnable; a simple autoplayer is slow to hit the last brick. The log shows every failure.
  • Not yet done: running the fix and variation prompts end to end. AI tools change, so steps may need small adjustments.
