    void isLockEnabled().then((enabled) => {
      setLocked(enabled);
      setLockEnabledState(enabled);

      const available = await biometricAvailable();
      setBiometricSupported(available);
      if (!available) {
        setBiometricEnabled(false);
        return;
      }
      setBiometricEnabled(await isBiometricUnlockEnabled());

真机验证点：
Android 11+ 已录入指纹/面部的设备：开启应用锁后，「我的」里出现「用指纹或面部解锁」；开启时会先弹一次系统验证，验证通过才保存为开启。

应用被杀掉重开后，锁屏页出现「用指纹解锁」按钮，并自动弹一次系统验证；验证通过直接进入应用。

系统验证失败或点取消：锁屏页保持，PIN 输入框照常可用；PIN 错误计数不因生物识别失败增加。

未录入任何生物特征的设备：「我的」里不出现这一行，锁屏页也没有按钮（不做假功能）。

Android 9 及以下（API < 29）或 Web 端：不出现开关和按钮，插件调用一律返回 false，不崩、不弹无意义对话框。

在「我的」里关闭生物识别后，锁屏页不再出现「用指纹解锁」按钮，也不自动弹验证。

连续输错 PIN 达到 10 次触发清除数据后，生物识别偏好也一并变 false；重新设置应用密码后该行为关闭。

未设置应用密码时点「用指纹或面部解锁」直接跳到设置应用密码页，不写入任何偏好。

系统设置里撤销指纹/面部录入后，应用下次启动时该开关不再显示，锁屏页也不再出按钮。
