你是 SecureInChat（加密群聊 App，React + TypeScript）的软件工程师。

## 输出格式（脚本自动应用，必须严格遵守）
每个文件输出为完整内容的块，块内不要再包 Markdown 代码围栏：
=== FILE: 相对仓库根目录的路径 ===
文件完整内容
=== END FILE ===

## 要做的事
1. 新文件 `apps/android-client/src/i18n/ns/messageSearch.ts`：
   `import type { Messages } from "../index";`，导出 `export const zh: Messages`、`export const en: Messages`、`export const es: Messages`。
   三个对象的键完全一致；键一律以 `messageSearch.` 开头（如 `messageSearch.title`）；参数用 `{name}` 占位，三种语言占位符一致。
2. 改写 `apps/android-client/src/screens/MessageSearchScreen.tsx`：所有给人看的文字（包括 aria-label、placeholder、title、alt、错误提示、按钮文字）改成 `t("messageSearch.xxx")`，`const t = useT();` 从 `"../i18n"` 导入。
   - 界面结构、样式、props、行为一律不变。不在组件外（模块顶层常量）调用 t；需要的话把常量挪进组件或改成键名。
   - 中文词条必须与原文**逐字相同**（现有测试按中文断言，必须原样通过）。
   - 日期、数字用 `Intl` 格式化时，locale 用 `useLocale()`（同样从 "../i18n" 导入）。
3. 英语自然简洁；西班牙语用中性拉美西语。语气平实准确，不夸大安全效果（不要写「完全安全」「无法破解」之类）。
4. 不加任何依赖；TypeScript strict，不用 any；保留现有注释。
5. 不要输出测试文件以外的其他文件；不要修改现有测试。

## 翻译层 API（apps/android-client/src/i18n/index.tsx，只读）
- `useT(): (key: string, params?: Record<string, string | number>) => string`
- `useLocale(): "zh" | "en" | "es"`
- 没有 Provider 时默认中文。

## 现有源码：apps/android-client/src/screens/MessageSearchScreen.tsx
import { useMemo, useState } from "react";
import { colors, touchTarget } from "@secureinchat/ui";
import { searchMessages } from "@secureinchat/chat-core";
import type { DisplayMessage } from "./ChatScreen";
import { formatMessageTime } from "../timeFormat";

export interface MessageSearchScreenProps {
  groupName: string;
  messages: DisplayMessage[];
  onBack: () => void;
}

/**
 * 消息搜索。全部在本地做——消息已经解密存在本机，中继上只有密文，
 * 服务端既搜不了也不该能搜。
 */
export function MessageSearchScreen({ groupName, messages, onBack }: MessageSearchScreenProps) {
  const [query, setQuery] = useState("");

  const searchable = useMemo(
    () =>
      messages.map((m) => ({
        id: m.id,
        text: m.text,
        media: m.media ? { fileName: m.media.fileName } : undefined,
        senderLabel: m.fromDeviceId,
        sentAtMs: m.sentAtMs,
        isOwn: m.isOwn,
      })),
    [messages]
  );

  const hits = useMemo(() => searchMessages(searchable, query), [searchable, query]);
  const trimmed = query.trim();

  return (
    <div style={{ minHeight: "100%", background: colors.ivory, display: "flex", flexDirection: "column" }}>
      <div style={{ display: "flex", alignItems: "center", gap: 8, padding: "12px 16px" }}>
        <button
          onClick={onBack}
          aria-label="返回"
          style={{
            background: "transparent",
            border: "none",
            boxShadow: "none",
            color: colors.deepInkGreen,
            cursor: "pointer",
            minHeight: touchTarget.minDp,
          }}
        >
          ←
        </button>
        <input
          type="text"
          value={query}
          onChange={(e) => setQuery(e.target.value)}
          placeholder={`在「${groupName}」中搜索`}
          aria-label="搜索关键词输入框"
          autoFocus
          style={{
            flex: 1,
            minHeight: touchTarget.minDp,
            border: `0.5px solid ${colors.sageMint}`,
            borderRadius: 20,
            padding: "0 16px",
            fontSize: 14,
            background: colors.ivory,
            color: colors.textPrimary,
            boxShadow: "none",
          }}
        />
      </div>

      <div style={{ flex: 1, overflowY: "auto", padding: "0 16px 16px" }}>
        {!trimmed ? (
          <p style={{ fontSize: 12, color: "#9A9A94", textAlign: "center", marginTop: 24 }}>
            输入关键词搜索本群的消息
          </p>
        ) : hits.length === 0 ? (
          <p style={{ fontSize: 12, color: "#9A9A94", textAlign: "center", marginTop: 24 }}>
            没有找到包含「{trimmed}」的消息
          </p>
        ) : (
          <>
            <div style={{ fontSize: 11, color: "#9A9A94", padding: "4px 0 8px" }}>
              找到 {hits.length} 条
            </div>
            {hits.map(({ message }) => (
              <div
                key={message.id}
                style={{
                  padding: "10px 0",
                  borderBottom: `0.5px solid ${colors.sageMint}`,
                }}
              >
                <div style={{ display: "flex", justifyContent: "space-between", marginBottom: 4 }}>
                  <span style={{ fontSize: 12, color: colors.deepInkGreen }}>
                    {message.isOwn ? "我" : (message.senderLabel ?? "对方")}
                  </span>
                  <span style={{ fontSize: 11, color: "#9A9A94" }}>{formatMessageTime(message.sentAtMs)}</span>
                </div>
                <div style={{ fontSize: 14, color: colors.textPrimary, wordBreak: "break-word" }}>
                  {message.text ?? `[文件] ${message.media?.fileName ?? ""}`}
                </div>
              </div>
            ))}
          </>
        )}
      </div>
    </div>
  );
}
