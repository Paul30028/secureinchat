# Multi-channel acquisition plan (draft, branch `next`, nothing live)

Sources: Grok and ChatGPT reviews on 2026-10-20 (independent answers; where they agree it is NOT independent evidence). Platform rules quoted by ChatGPT are unverified by us until checked on the platform's own page.

## Agreed by both
- One screen recording, reused across platforms, is an efficiency tactic, not a proven acquisition model.
- Topics must be specific and solve a task (remove GPS from a photo, redact secrets from a screenshot, what a DNS leak test can/cannot prove, batch site check). Generic "stay private" content has no search intent.
- Short-video link limits are the main conversion risk. Primary conversion path: long-form video description, channel page, and search/SEO pages.
- Success metric: referral visits and completed tool uses, not views. Search volume/CTR for our terms is unknown; measure it ourselves.
- No bulk posting, no bought lists, no ads. Human time <= 15-20 min/day, so fewer channels done well.

## Priority (ChatGPT; Claude agrees, Grok ranks video higher)
- P0 SEO: 4 tutorial pages, one per tool, each with clear search intent.
- P1 YouTube: 1 full demo + 3 short clips with distinct informational value. Reddit: real answers first, follow each subreddit's rules, disclose affiliation; Paul posts.
- P2 Show HN / Product Hunt (one-off launch, not sustained traffic).
- P3 TikTok / Reels / directories: only with spare capacity.

## To verify before relying (Paul or Claude via official help pages)
- YouTube policy on repetitive/mass-produced content; whether Shorts descriptions allow clickable links.
- TikTok link rules (reported: personal accounts need ~1,000 followers or a business account; varies by region).
- Instagram link rules; creator-programme eligibility for a mainland-China owner (not counted as income).

## Measurement (needs Paul's go-ahead: touches the live site and privacy table)
Privacy site, so no cookies or per-user tracking. Use aggregate, cookie-less counters only: referrer/UTM per channel and a "tool completed" count with no content. ChatGPT proposed per-channel UTM and completion events; keep them aggregate and list them in the privacy table.

## 14-day experiment
Days 1-2: set up aggregate tracking (on `next`, Paul decides go-live). Days 3-7: publish 4 SEO tutorials (one tool first), 1 demo video + 3 clips, 1-2 rule-compliant community answers. Days 8-14: adjust by referral visits and completions.
Stop: any platform warning -> pause that channel; a channel with no attributable visits after two content rounds -> pause; visits but no completions -> fix page trust, speed, flow first. 14 days cannot judge SEO's long-term value.

## Likeliest failures
1. Watching impressions, not completions. 2. Content that reads as advertising, so privacy-trust is lost. 3. Too many channels, samples too small to tell which works. (Grok adds: link not on main path; daily time over budget.)

## Open disagreement
Grok: short-video multi-post early. ChatGPT: SEO + long video first, shorts later. Claude: follow ChatGPT order; shorts only as cuts of videos already made.
