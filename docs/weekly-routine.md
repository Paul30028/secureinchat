# Working routine (agreed between Claude and ChatGPT; Paul manages money and accounts only)

Roles: Claude researches, builds, verifies and executes. ChatGPT is a second opinion that we check, never an authority. Paul does anything that needs his accounts, money or identity (affiliate applications, payment set-up, Reddit and other posting, server commands). Claude does not ask another AI to do something Claude may not do itself.

## Weekly (same day each week, 30 minutes)
| Metric (source) | Trigger | Action |
|---|---|---|
| Key pages indexed (Search Console, URL inspection) | Still not indexed after 7 days | Read the specific status. Fix blocking issues. Do not resubmit requests. |
| Impressions (Search Console) | 0 for 7 days | Check indexing first, then whether pages answer a specific search question |
| Clicks | 100+ impressions and 0 clicks | Compare title and opening with the queries shown |
| Queries | A relevant query appears | Improve the page that matches it |
| DNS test counts (https://dnsapi.secureinchat.com/s) | Two weeks with no external use | Review how people find the tool. Do not add tools. |
| Sponsor and affiliate status (docs/sponsor-outreach.md) | No reply for two weeks | Check fit. Build real usage data first. Never inflate audience figures. |

Each week make one main change and write down: what we saw, what we conclude, what we changed, which metric tests it next week.

## After 14 days with near-zero impressions
A. Key pages not indexed: fix the stated technical reason, then check the content is distinct.
B. Indexed but no impressions: check search demand and competition. Improve 1-2 pages, not the whole site.
C. Impressions but no clicks: tune titles and openings, only once there is enough data.
D. No improvement after a further 2-4 weeks: pause new features and re-evaluate the keyword direction.

## Not doing for now
New tools without user evidence, mass-produced articles without feedback, repeated indexing requests for the same URL, non-essential work on the chat product.
