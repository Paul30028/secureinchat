## 做了什么

**数据**:Echap stalkerware-indicators,CC-BY 4.0(在 README 的 License 一节核对过，链接到 creativecommons.org/licenses/by/4.0/)。`tools/update_stalkerware.py` 用 `git ls-remote` 钉住源提交(本次 `426156175adc`),只取 **C2 服务器域名**,不取厂商官网——否则在浏览器里查资料的记者也会被告警。结果:993 个域名(跟踪软件 929、家长监控/远程管理类 64);其中 128 个同时是官网，告警措辞会说明「如果只是在浏览它的网站，可以忽略」。检查过：名单里没有单独列出 firebaseio.com、appspot.com 等共享平台根域名(否则所有用这些平台的 App 都会触发)。

**core**:`SpywareDb` 按标签边界匹配(列出的域名本身或其子域名;`notcopy9.com` 不算);加载时丢弃共享平台根域名。`SpywareWatch` 每个域名 6 小时最多告警一次，只在内存里保留最近 20 条，线程安全。

**app**:每个 DNS 查询(无论拦截还是放行)都检查;命中时：
- 单独的「安全提醒」通知渠道(高优先级);**锁屏上只显示「Guardian 有一条安全提醒 / 解锁后查看」**,不露 App 名和域名;
- 解锁后的内容：跟踪软件名、域名、「Guardian 无法知道是哪个 App」、「没有替你拦截，以免惊动安装它的人」;家长监控类和兼作官网的域名措辞更温和;
- 主界面：告警列表 + 安全建议(身边的人：先别删、先截图、找可信的人或机构;政府或专业攻击者：把手机当作已暴露，敏感的事换干净设备);
- 一行常驻说明:「正在留意 993 个已知跟踪软件服务器。没有提醒不代表没有跟踪软件：名单不完整，高级间谍软件也可能绕过 Guardian。」——不显示「安全」;
- 页面底部 Echap 署名(CC-BY 要求)。
