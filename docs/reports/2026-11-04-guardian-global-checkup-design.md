# Guardian 设计方向：面向全球、包括高风险用户的「应用体检 + 动态告警」(Claude Code,2026-11-04)

Paul 的方向(11-04):使命是为全人类的隐私权，不只是低风险地区;建议加「搜索」，标出哪些 App 打开了非必要的权限和隐私开关并告警，以及动态告警。Paul 授权按这个目标设计。下面是设计;**代码未动**,请项目经理审查、排进任务板。

## 0. 和现有规则的关系

- 规则 5(不做针对中国的翻墙/规避审查宣传)**不变**。面向高风险用户的方向是「保护隐私、发现监控」,不是规避审查，两者不冲突。
- 不加依赖、Guardian 没有服务器、不联网(除了转发 DNS)这几条也不变。下面所有能力都只用安卓框架 API。

## 1. 高风险用户真正怕什么

低风险用户怕「被广告追踪」;高风险用户(记者、维权者、家暴受害者、少数群体)怕的是**被人盯上**:伴侣/家人装的跟踪软件(stalkerware)、被偷偷开的无障碍服务和设备管理员、长期掌握位置和麦克风的 App。只是「列出谁有相机权限」解决不了他们的问题;要把**真正危险的信号**挑出来，并告诉他们**安全地**怎么办。

特别要注意：对家暴受害者，**直接删掉跟踪软件可能会惊动对方**(对方发现收不到数据)。所以 Guardian 只告知、不自动删除、不自动拦截，并先给安全建议(见第 5 节)。

## 2. 功能设计

### 2.1 应用体检(「检查」标签的核心;Paul 说的「搜索」)

一次扫描，分三层显示，**只摆事实，不下「这个 App 是坏的」的判决**:

**第一层：可能被监控(高风险，红色)**
- **疑似跟踪软件**:已装 App 的包名或签名证书命中 Echap 跟踪软件特征库(CC-BY;149 个跟踪软件 + 27 个「家长监控类」，后者单独标注，不和跟踪软件混为一谈)。
- **能读取屏幕内容的 App**:已开启的无障碍服务(`AccessibilityManager.getEnabledAccessibilityServiceList`)。这是跟踪软件和银行木马最常用的手段。
- **设备管理员**(`DevicePolicyManager.getActiveAdmins`):可以锁屏、擦除数据，防止被卸载。
- **能读取所有通知的 App**(通知使用权):能看到聊天内容、验证码。**能否读到别的 App 的这个状态要在模拟器上先验证**,读不到就不显示这一项(不做假功能)。
- **隐藏了桌面图标、却有敏感权限的 App**(没有启动入口 + 有位置/麦克风/短信等权限)。

**第二层：可能不必要(黄色)**
- **长期没用、仍握着敏感权限**:例如 30 天没打开，却有后台位置/麦克风/相机/通讯录/短信/通话记录权限。这是对「非必要」最可靠的判断。需要用户在系统里给 Guardian 开「使用情况访问」;不开就不显示这一层，并说明为什么。
- **后台位置**:比「使用时位置」危险得多，单独列出。
- (G17)**含有追踪库**:按 Exodus 代码签名，写「含有」不写「在用」。

**第三层：按权限浏览(中性)**
- 位置、麦克风、相机、通讯录、短信、通话记录、附近设备、身体传感器：每类有多少 App 已获授权，点进去看是哪些。
- 顶部**搜索框**:按 App 名字搜，看它拿了哪些权限、有没有追踪库、多久没用。

每个 App 的详情页：已授予的敏感权限、命中的信号(为什么被列出来)、追踪库;两个按钮：**打开它的权限设置**、**卸载**。Guardian 自己**不改任何设置**。

### 2.2 动态告警(Guardian 开着时)

只对**少数高信号事件**推送，其余都留在体检页，避免「告警疲劳」:

| 事件 | 怎么发现 | 推送内容示例 |
|---|---|---|
| 连接了已知跟踪软件的服务器 | Guardian 本来就看得到每个 DNS 查询;对照 Echap 的 C2 域名 | 「有 App 连接了已知跟踪软件的服务器」 |
| 新开启了无障碍服务 | 监听系统设置变化(ContentObserver) | 「『某某』刚获得读取屏幕内容的能力」 |
| 新增设备管理员 | Guardian 运行时定期比对 | 「『某某』刚成为设备管理员」 |
| 新装的 App 一次拿到高风险组合 | 运行时监听安装事件 + 检查权限 | 「新安装的『某某』有后台位置和麦克风权限」 |

- **默认只告警、不拦截**跟踪软件服务器(见第 1 节，拦截可能惊动对方);用户可以在详情里自己选择拦截。
- **锁屏上默认用中性文字**(「Guardian 有一条安全提醒」)，不在锁屏写 App 名和内容;用户可以改成详细显示。

### 2.3 「如果你担心被监控」指引页

- 先评估安全：如果担心对方察觉，先不要删除、先保存证据、先找可信的人或机构。
- Guardian 做不到的要明说：查不出高级间谍软件(零点击类);干净的结果不等于没有被监控(Echap 也这样写)。
- 外部求助资源(做之前核对链接和机构名称):stopstalkerware.org(受害者指引)、Access Now 数字安全求助热线、Amnesty 的 Mobile Verification Toolkit(给专业人员)。

## 3. 隐私设计(高风险用户的手机可能被别人拿走)

- **扫描结果不落盘**:每次打开现算，只在内存里。
- 动态告警需要「上次的状态」来比对：只存每个 App 的(包名 + 权限集合)加盐哈希，不存可读的 App 清单;并说明哈希仍可能被对照猜出(不夸大)。设置里可以整个关掉动态告警，关掉即删除这些哈希。
- 告警记录只存在通知栏;Guardian 内不另存历史。
- 应用锁(聊天 App 已有，Guardian 没有)可作为后续选项。

## 4. 技术可行性(都只用框架 API)

| 能力 | API | 版本 | 状态 |
|---|---|---|---|
| 列出所有 App 和权限授予情况 | `PackageManager.getInstalledPackages(GET_PERMISSIONS)` + `requestedPermissionsFlags` | 需要 QUERY_ALL_PACKAGES(Paul 11-01 已授权;Play 上架要申报用途) | 可行 |
| 签名证书比对 | `GET_SIGNING_CERTIFICATES` | API 28+;26–27 用旧接口 | 可行 |
| 无障碍服务 | `AccessibilityManager.getEnabledAccessibilityServiceList` | 全部 | 可行 |
| 设备管理员 | `DevicePolicyManager.getActiveAdmins` | 全部 | 可行 |
| 通知使用权 | 读系统设置 | 不确定 | **先验证** |
| 多久没用 | `UsageStatsManager`(用户手动授权「使用情况访问」) | 全部 | 可行(可选) |
| 无桌面入口 | `getLaunchIntentForPackage == null` | 全部 | 可行(注意系统 App 误报，排除系统 App) |
| 跟踪软件 C2 域名告警 | 现有 DNS 处理路径 + 新名单 | 全部 | 可行，成本最低 |

需要改 `policy_check.py`:允许 QUERY_ALL_PACKAGES 和 PACKAGE_USAGE_STATS 两个权限，并注明用途。

## 5. 建议任务(按价值和成本排序)

| # | 任务 | 说明 |
|---|---|---|
| G20 | 跟踪软件特征库 + DNS 告警 | `tools/update_stalkerware.py` 从 Echap 生成资产文件(署名 CC-BY,**先核对确切的许可证版本**);core 里对 DNS 查询做匹配(像 TrackerDb);命中时推送中性告警，默认不拦截。成本最低、对高风险用户价值最高 |
