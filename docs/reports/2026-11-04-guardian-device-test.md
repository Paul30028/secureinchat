# Guardian 新版真机测试清单(U1–U3,2026-11-04)

**APK**:CI 运行 [41849627366](https://github.com/Paul30028/secureinchat/actions/runs/41849627366) 页面底部的 `guardian-debug-apk`(登录 GitHub 后下载,解压得到 `app-debug.apk`)。分支 `feature/U1` a4007f4。这个版本在模拟器 Android 10 和 Android 14 上整条自动测试已通过;**真机没测过**。

装之前:如果手机上有旧版 Guardian,先卸载(debug 签名一样可以覆盖安装,但卸载能看到「第一次打开」的说明页)。

每项写「通过 / 不通过 + 看到了什么」。最后写手机型号和 Android 版本。
