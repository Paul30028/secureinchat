# Sponsor report template (monthly)

Use only numbers we can show. Exclude our own testing and say so.

## Wording
**DNS test activity (aggregate, server-side)**
- Confirmed tests: the number of tests whose unique DNS query reached our authoritative server (source: https://dnsapi.secureinchat.com/s, field `confirmed`).
- Completed tests: confirmed tests whose result the page then read back (`completed`).
- These are technical test events, not a count of people. One person can run several tests, and one resolver address is counted at most 30 new tests per hour. Our own testing is not removed from the raw numbers, so state the dates we tested and subtract them.

**Search (Google Search Console)**: impressions and clicks for the period, copied as shown.

**Placement**: page, position, impressions of the placement (page views of that page), outbound clicks. If a figure is not measured, write "not measured".

## Never write
- "visitors", "users" or "audience" for the test counts.
- Cloudflare "visits": they include scanners and our own tests.
- Any projection.

## Checklist before sending
- Numbers copied from the sources above, with the date they were read.
- Our own test dates listed.
- Placement labelled as sponsored or affiliate on the page.
