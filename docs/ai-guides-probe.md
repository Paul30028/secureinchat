## Assessment (hypotheses, not evidence)
+ Strong, growing interest; long-tail by game type/platform (Roblox, mobile, 2D assets).
+ AI can do most of the work, and can VERIFY each guide by actually following it and recording the result (proof of a working build).
- Fast decay: tools/UI/models change; guides need re-testing. Vendors (Replit, Roblox, Figma) compete directly and rank first.
- Prompt packs are a low-barrier crowded product; revenue unproven.
- Quality bar: a guide is worth reading only if its steps reproduce. Unverified guides are the common failure (the owner already rejected a low-quality game build; same standard applies).
- Money path unproven: free content + affiliate/ads, or paid guide; needs distribution (video/SEO).

## Cheapest test (AI side)
Pick 2 game types (e.g. a simple 2D browser game, a Roblox obby). For each: AI follows its own steps end-to-end with a named tool, records exact prompts, failures and fixes, produces a working result + a 5-8 step guide. Then compare: video views for that exact topic, search impressions after publishing (owner's call), reader questions. Stop if steps fail to reproduce twice or interest stays flat after 4-8 weeks.
