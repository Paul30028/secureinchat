# 邀群密聊 Next 真机测试清单(K4)

安装：本页一起发的 `secureinchat-debug.apk`(来自 `feature/chat` 的 CI 构建)。最好两台手机;只有一台就和模拟器或网页版配合。每一项写「通过 / 不通过 + 看到了什么」,最后写两台手机的型号和 Android 版本。

| # | 操作 | 应该看到 | 结果 |
|---|---|---|---|
| 1 | 手机 A 建群，生成邀请;手机 B 扫码加入 | B 进群，两边都看到对方 | |
| 2 | 互发文字 | 几秒内到达 | |
| 3 | 互发图片、语音、文件 | 能看/能听/能打开 | |
| 4 | 一对一语音通话 | 能接通、双方能听到 | |
| 5 | 群设置里打开「5 分钟后消失」,发一条消息 | 有沙漏标记，5 分钟后两边都消失 | |
| 6 | 开应用锁和指纹，退到后台再回来 | 要求解锁，指纹能解 | |
| 7 | 聊天页截屏 | 截不了或是黑屏 | |
| 8 | 「我的」→ 备份 → 输两遍密码 → 生成备份文件 | **弹出系统保存对话框**,选位置后提示「备份已保存」 | |
| 9 | 在保存对话框点取消 | 不报错，密码还在 | |
| 10 | 用刚才的文件恢复(选文件 → 密码 → 预览 → 确认) | 显示要恢复的群和消息数，确认后恢复 | |
| 11 | 一台手机开飞行模式 1 分钟再关 | 自动重连，期间的消息能收到 | |
| 12 | 设置 → 应用 → 权限 | 没有存储权限(保存文件不需要它) | |
