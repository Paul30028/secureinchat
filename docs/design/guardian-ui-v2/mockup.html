隐私检查

三项系统设置，每项约 1 分钟。Guardian 只帮你打开对应的设置页，不读取你的设置。

删除广告 ID
广告 ID 让各个 App 把你的行为串起来。Android 12 及以上删除后，App 拿到的是空白 ID。
打开广告设置 ›
关掉精确位置
很多 App 只需要大致位置。精确位置能定位到几米内。
打开位置设置 ›
检查应用权限
Android 11 及以上可开启「App 未使用时移除权限」。
打开应用设置 ›
